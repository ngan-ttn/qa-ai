# Database Terms

## Purpose

This document defines standardized terminology related to database concepts and data management.

Its purpose is to establish a shared vocabulary across the QA-AI framework, ensuring that database-related documentation, skills, workflows, templates, and testing artifacts use consistent terminology.

---

## C

### Column

**Definition**

A field within a database table that stores a specific type of data for each record.

**Related Terms**

- Table
- Row
- Data Type

---

### Constraint

**Definition**

A rule applied to database data to ensure integrity, consistency, and validity.

**Related Terms**

- Primary Key
- Foreign Key
- Unique Constraint

---

## D

### Data Integrity

**Definition**

The accuracy, consistency, and reliability of data throughout its lifecycle.

**Related Terms**

- Constraint
- Transaction
- Data Consistency

---

### Data Type

**Definition**

A classification that defines the type of values a database column can store.

**Related Terms**

- Column
- Schema

---

### Database

**Definition**

An organized collection of structured data managed by a database management system.

**Related Terms**

- Table
- Schema
- Database Management System

---

### Database Management System (DBMS)

**Definition**

Software used to create, manage, query, and maintain databases.

**Related Terms**

- Database
- SQL
- Transaction

---

## F

### Foreign Key

**Definition**

A column or set of columns that establishes a relationship between two database tables.

**Related Terms**

- Primary Key
- Relationship
- Constraint

---

## I

### Index

**Definition**

A database structure that improves the speed of data retrieval operations.

**Related Terms**

- Query
- Table

---

## J

### Join

**Definition**

An operation that combines data from multiple tables based on related columns.

**Related Terms**

- Table
- Foreign Key
- Query

---

## P

### Primary Key

**Definition**

A column or combination of columns that uniquely identifies each record within a table.

**Related Terms**

- Foreign Key
- Constraint
- Unique Constraint

---

## Q

### Query

**Definition**

A request to retrieve, insert, update, or delete data within a database.

**Related Terms**

- SQL
- Table

---

## R

### Record

**Definition**

A single row of data stored within a database table.

**Related Terms**

- Row
- Table
- Column

---

### Relationship

**Definition**

A logical association between database tables established through related keys.

**Related Terms**

- Foreign Key
- Primary Key
- Join

---

### Row

**Definition**

A collection of related column values representing a single record in a database table.

**Related Terms**

- Record
- Table
- Column

---

## S

### Schema

**Definition**

The logical structure that defines database objects, relationships, and organization.

**Related Terms**

- Database
- Table
- Column

---

### SQL (Structured Query Language)

**Definition**

A standardized language used to define, manipulate, and query relational databases.

**Related Terms**

- Query
- Database
- Transaction

---

## T

### Table

**Definition**

A database object that organizes related data into rows and columns.

**Related Terms**

- Row
- Column
- Schema

---

### Transaction

**Definition**

A sequence of database operations executed as a single logical unit of work.

**Related Terms**

- Commit
- Rollback
- Data Integrity

---

## U

### Unique Constraint

**Definition**

A database constraint that ensures all values within a column or column combination remain unique.

**Related Terms**

- Primary Key
- Constraint

---

## V

### View

**Definition**

A virtual table created from the result of one or more database queries.

**Related Terms**

- Query
- Table
- Schema
