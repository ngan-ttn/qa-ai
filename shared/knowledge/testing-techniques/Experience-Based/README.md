# Experience-Based Testing Techniques

## Purpose

This category captures techniques that use tester learning, defect history, heuristics, observation, and adaptive investigation to complement formal test design.

## Scope

```text
Experience-Based/
├── Error-Guessing.md
├── Exploratory-Testing.md
├── Session-Based-Testing.md
└── Checklist-Based-Testing.md
```

## Relationships

Error Guessing forms testable hypotheses from experience. Exploratory Testing adapts design during execution. Session-Based Testing adds charter/time-box/debrief structure. Checklist-Based Testing reuses curated reminders across contexts.

## Quality Boundary

Experience-based work should not become untraceable random testing. Important findings require reproducible evidence and high-value discoveries should feed regression, checklists, risk analysis, or formal scenarios.
