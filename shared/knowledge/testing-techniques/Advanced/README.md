# Advanced Testing Techniques

## Purpose

This category covers specialized or emerging techniques whose cost, tooling, safety requirements, or reasoning model go beyond routine test-design methods.

## Scope

```text

├── Prompt-Based-Test-Generation.md
└── Chaos-Testing.md
```

## Selection Guidance

- **Mutation Testing** evaluates test fault-detection sensitivity.
- **Fuzz Testing** explores unexpected input spaces.
- **Property-Based Testing** validates general invariants across generated inputs.
- **AI-Assisted Test Design** uses AI under grounding and review controls.
- **Prompt-Based Test Generation** structures AI generation through explicit prompt contracts.
- **Chaos Testing** validates resilience with controlled failure experiments.

## Quality Boundary

Advanced does not mean universally better. Technique selection must be driven by risk, objective, authorization, environment safety, and expected value.
